# 🌤️ Weather App (Python)

## Description
This is a **Python console application** that fetches and displays real-time weather information for any city using the **OpenWeatherMap API**.  

It demonstrates:
- Working with APIs (`requests` library)
- JSON parsing
- Handling user input and errors
- Optional: country code support

---

## Features
- Fetch current weather for any city worldwide  
- Display temperature (°C), humidity, wind speed, and weather description  
- Handle invalid city names or API errors gracefully  
- Loop for multiple queries without restarting the program
